---

## 1. 项目概览

面向跨境卖家的智能备货决策系统，核心链路：**数据归集 → 每日测算 → 备货建议 / 缺货滞销预警 / 采购计划 → 执行回写**。

单体仓库（monorepo）双进程：

- **后端** `backend/`：FastAPI 单层 API，进程内 APScheduler 定时测算。
- **前端** `frontend/`：React 18 + Vite SPA，`/api` 反向代理到后端。
- **数据库**：SQLite 单文件（默认）或 PostgreSQL（生产推荐）。

## 2. 技术栈与端口

| 组件 | 技术 | 默认端口 |
|---|---|---|

## 5. 本地开发部署

### 5.1 后端

```bash
cd backend

# 创建虚拟环境（推荐 uv；或 python -m venv .venv）
uv venv .venv --python 3.12
source .venv/Scripts/activate   # Windows；Linux/macOS 用 .venv/bin/activate

# 安装依赖
uv pip install -r requirements.txt
# 或：pip install -r requirements.txt

# 初始化数据库（建表 + 迁移 + 导入 mock）
python -m alembic upgrade head
python -m app.core.seed --mock

# 启动（开发热重载）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 5.2 前端

```bash
cd frontend
npm install
npm run dev          # 开发服务器 http://localhost:5173
```

### 5.3 验收

```bash
cd backend && pytest                                  # 27 个用例
cd .. && bash verify/stage0.sh … bash verify/stage7.sh # 分阶段验收门
bash verify/e2e.sh                                    # 全链路冒烟 + 生成验收报告.md
```

## 6. 生产部署（裸机 + Nginx + PostgreSQL）

### 6.1 数据库切换到 PostgreSQL

```bash
export DATABASE_URL="postgresql+psycopg://user:password@127.0.0.1:5432/stockwise"
# 需先安装驱动：pip install psycopg[binary]
cd backend
python -m alembic upgrade head
python -m app.core.seed --mock
```

### 6.2 后端（systemd + uvicorn 多 worker）

`/etc/systemd/system/stockwise.service`：

```ini
[Unit]
Description=StockWise Backend
After=network.target

[Service]
WorkingDirectory=/opt/stockwise/backend
Environment=DATABASE_URL=postgresql+psycopg://user:password@127.0.0.1:5432/stockwise
ExecStart=/opt/stockwise/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now stockwise
```

> 说明：APScheduler 定时任务随主进程启动，多 worker 下请确保仅一个进程承载调度（可用单 worker，或后续将调度拆到独立进程，避免重复测算）。

### 6.3 前端（构建 + Nginx）

```bash
cd frontend && npm run build   # 产物在 frontend/dist
```

`/etc/nginx/conf.d/stockwise.conf`：

```nginx
server {
    listen 80;
    server_name stockwise.example.com;

    root /opt/stockwise/frontend/dist;
    index index.html;

    # SPA 路由回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
nginx -t && systemctl reload nginx
```

## 7. Docker 部署（推荐）

> 仓库当前未内置 Dockerfile，以下为可直接落地的标准配置，可按需添加到仓库根目录。

### 7.1 后端 `backend/Dockerfile`

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY backend/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY backend/ ./backend/
COPY mock/ ./mock/
WORKDIR /app/backend
EXPOSE 8000
CMD ["sh", "-c", "alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port 8000"]
```

### 7.2 前端 `frontend/Dockerfile`（多阶段构建）

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY frontend/package*.json ./
RUN npm ci
COPY frontend/ ./
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY frontend/nginx.conf /etc/nginx/conf.d/default.conf
```

### 7.3 `docker-compose.yml`（根目录）

```yaml
services:
  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: stockwise
      POSTGRES_PASSWORD: stockwise
      POSTGRES_DB: stockwise
    volumes:
      - pgdata:/var/lib/postgresql/data

  backend:
    build:
      context: .
      dockerfile: backend/Dockerfile
    environment:
      DATABASE_URL: postgresql+psycopg://stockwise:stockwise@db:5432/stockwise
    depends_on:
      - db
    ports:
      - "8000:8000"

  frontend:
    build:
      context: .
      dockerfile: frontend/Dockerfile
    ports:
      - "80:80"
    depends_on:
      - backend

volumes:
  pgdata:
```

```bash
docker compose up -d --build
```

## 8. 数据库迁移（Alembic）

```bash
cd backend
python -m alembic upgrade head       # 升级到最新
python -m alembic current            # 查看当前版本
python -m alembic revision --autogenerate -m "描述"  # 生成新迁移（模型变更后）
python -m alembic downgrade -1       # 回退一个版本
```

## 9. 定时任务（APScheduler）

- 默认每日 **06:30** 自动全量测算 + 预警扫描（进程内调度，随后端启动）。
- 环境变量覆盖：`CALC_CRON_HOUR`、`CALC_CRON_MINUTE`。
- 手动触发（开发/补跑）：`POST /api/calc/run`。

---

## 10. 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DATABASE_URL` | `sqlite:///data/stockwise.db` | 数据库连接串；生产切 PostgreSQL |
| `CALC_CRON_HOUR` | `6` | 每日测算触发小时 |
| `CALC_CRON_MINUTE` | `30` | 每日测算触发分钟 |

> 业务参数（权重/系数档位/阈值/备货周期/预算/大促日历）不走环境变量，统一存 `settings` 表，页面「系统设置 / 预警规则」可改。

## 11. 初始化与验收清单

1. `alembic upgrade head` 建表。
2. `python -m app.core.seed --mock` 导入商品档案 + 大促日历 + 默认参数。
3. 启动后端，`GET /api/health` 返回 `{"code":0,"data":{"status":"ok"}}`。
4. 数据中心上传 6 个 mock CSV → 测算 → 建议/预警/采购/问答走通（`bash verify/e2e.sh` 一键验证）。

## 12. 常见问题排查

| 现象 | 处理 |
|---|---|
| 前端 build 报 TS1484 | 类型导入需用 `import type { X }`（`verbatimModuleSyntax` 开启） |
| SQLite 锁 / 并发写入 | 生产改用 PostgreSQL，避免 SQLite 单写瓶颈 |
| 定时测算重复执行 | 多 worker 下调度需单进程承载；或仅 `--workers 1` |
| 导入 CSV 中文乱码 | CSV 需 UTF-8（带 BOM 亦可），适配器按 `utf-8-sig` 读取 |
| 远程推送 GitHub 失败 | 配置代理：`git config --global http.proxy http://127.0.0.1:7890` |
| 外部信号缺失 | 系统按「沿用上一期 + data_flags 标记」降级，不中断 |
