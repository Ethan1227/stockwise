## 一、项目概述

**一句话定位**：面向亚马逊/沃尔玛跨境卖家的智能备货决策系统，把「拍脑袋补货」变成「数据驱动决策」。

- **目标用户**：年营收约 500 万的跨境电商卖家
- **核心价值**：
  - 自动测算每日补货量，减少缺货 / 滞销损失
  - 提前预警缺货与滞销风险，规避损失
  - 采购计划一键生成，到货自动回写库存
  - AI 问答助手，用自然语言直接查备货结论

## 二、核心业务链路

```
数据归集 → 每日测算 → 备货建议 / 缺货滞销预警 / 采购计划 → 执行回写
```

- **数据归集**：导入亚马逊订单、沃尔玛订单、库存快照、竞品情报、行情趋势、环境评分
- **每日测算**：基线日销 × 四修正器 → 预测日销 → 备货评分 → 建议备货量
- **决策输出**：备货建议表、缺货/滞销预警、采购计划
- **执行回写**：采购单确认 → 发货 → 到货，自动联动在途与库存

## 三、技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 前端 | React 18 + Vite + TypeScript + Tailwind CSS + Recharts + TanStack Query | SPA，响应式（支持手机） |
| 后端 | Python 3.12 + FastAPI + SQLAlchemy 2 + Pydantic v2 | 单层 REST API |
| 数据库 | SQLite（本地）/ PostgreSQL（生产） | Alembic 迁移管理 |
| 定时任务 | APScheduler | 独立进程，每日 06:30 自动测算 |
| AI | DeepSeek（deepseek-v4-flash） | 问答助手 + SSE 流式输出 |
| 部署 | Docker Compose | db + backend + scheduler + frontend 四服务 |

**系统分层**：数据源适配层（可插拔）→ 标准表 → 测算引擎（可插拔）→ 结果落表 → 编排服务 → 预警规则（可插拔）→ API 层。

## 四、已完成功能（9 大模块）

> **演示地址**：`https://awning-compactor-unsuited.ngrok-free.dev`（ngrok 临时公网地址，可能变动；每模块附演示页链接，点击直达对应页面）。

### 1. 工程骨架
- 9 张业务表 + Alembic 迁移 + 健康检查 + 数据种子脚本
- 前端布局壳（深色侧边导航 + 顶栏 + 卡片式内容区）
- 🔗 演示：[工作台（默认入口）](https://awning-compactor-unsuited.ngrok-free.dev/)

### 2. 数据中心
- 6 类 CSV 数据源适配器（可插拔注册）
- 上传导入 API（幂等、缺列校验返回错误明细、行级错误报告）
- 数据源状态与导入日志
- 🔗 演示：[数据中心](https://awning-compactor-unsuited.ngrok-free.dev/datacenter)

### 3. 测算引擎
- 基线日销 = 近30天×0.5 + 近90天×0.3 + 去年同期×0.2
- 4 个修正器（趋势/竞品/大促/环境），可插拔、注销自动降级为 1.0
- 备货评分（缺货紧迫 40 + 销售健康 25 + 外部信号 25 + 资金效率 10）
- 建议备货量 = 预测日销 × 备货周期 − 可售 − 在途，按 MOQ 取整
- 手动触发 + 每日 06:30 自动触发
- 🔗 演示：[备货建议表「重新测算」触发](https://awning-compactor-unsuited.ngrok-free.dev/suggestions)

### 4. 备货建议表
- 建议列表（按评分降序、平台/评分档筛选）
- 评分徽章分档（≥80 红 / 60-79 橙 / 40-59 灰 / <40 蓝）
- 人工改量 / 忽略（独立持久化，重算不丢）
- 评分依据抽屉（四维度 Progress 条 + 测算依据）
- Excel 导出
- 🔗 演示：[备货建议表](https://awning-compactor-unsuited.ngrok-free.dev/suggestions)

### 5. 预警中心
- 4 条内置规则（缺货紧急/缺货一般/滞销严重/滞销轻度），阈值可配置
- 同一预警不重复创建
- 通知器（站内信 + 邮件，SMTP 未配置自动降级）
- 预警处理 / 忽略
- 🔗 演示：[预警中心](https://awning-compactor-unsuited.ngrok-free.dev/alerts)

### 6. 采购计划
- 勾选建议 → 按供应商分组生成采购草稿
- 预算校验（超预算 warning）+ 交期倒排（大促临近提示改空运）
- 状态机：草稿 → 确认 → 发货 → 到货，自动回写在途/库存
- 手工补录历史采购单 + Excel 导出
- 🔗 演示：[采购计划](https://awning-compactor-unsuited.ngrok-free.dev/purchase)

### 7. 工作台总览

- 全店销量趋势图（亚马逊/沃尔玛双折线）
- 数据接入状态 + 今日待办（含黑五倒计时）
- 🔗 演示：[工作台总览](https://awning-compactor-unsuited.ngrok-free.dev/)

### 8. AI 问答助手

- SSE 流式输出 + 思考过程（可折叠展示）
- LLM 不可用时自动降级为规则模板回答

- 🔗 演示：[系统设置](https://awning-compactor-unsuited.ngrok-free.dev/settings)

## 五、技术亮点

1. **可插拔架构**：数据源 / 修正器 / 预警规则均可热插拔，注销后自动降级，不影响系统运行
2. **LLM 集成**：规则路由 + 大模型生成，双保险（LLM 挂了仍能用模板回答）
3. **SSE 流式**：AI 问答逐字输出，带思考过程
4. **调度独立进程**：测算与 API 解耦，多 worker 下不重复触发
5. **Docker 一键部署**：四服务编排，健康检查 + 数据持久化
6. **移动端适配**：汉堡侧边栏、表格横向滚动、弹窗全屏
