## 验算示例（SK-2087，默认参数）

```
基线日销 ≈ 近30天9×0.5 + 近90天8×0.3 + 去年同期14×0.2 ≈ 9.7（精确值以 mock 数据实算为准）
预测日销 ≈ 9.7 × 趋势1.0 × 竞争1.0 × 事件1.0 × 环境1.0 ≈ 9.7
可售天数 = 45 ÷ 9.7 ≈ 4.6 天 < 头程35天 → 缺货·紧急
建议备货 = 9.7 × (7+35+5+10) − 45 − 400(在途) ≈ 108 → MOQ 200 取整 = 200
（若剧情需要 450 件，可将 purchase_orders_history 中 SK-2087 在途改为 0 后重跑）
```

> 注意：本 mock 为固定随机种子生成，重算结果以上述数量级为准；验收时允许 ±10% 浮动，重点验"规则触发正确 + 公式口径一致"。

# mock/ — 模拟单据 CSV

> 来自开发包的模拟数据，导入测试用。**实际数据文件需从开发包落位到本目录**，字段 schema 由 Stage 0/1 实现时对齐（以开发包 CSV 为准，勿凭空臆造）。

## 文件清单与用途

| 文件 | 用途 | 放入时机（阶段） |
|---|---|---|
| sku_master.csv | 商品档案（8 个 SKU，含双平台字段） | S0 seed 自动导入 |
| amazon_orders.csv | 亚马逊订单（约 696 行） | S1 验收 |
| walmart_orders.csv | 沃尔玛订单（约 348 行） | S1 验收 |
| inventory_snapshot.csv | 库存快照（8 行，幂等） | S1 验收 |
| competitor.csv | 竞品情报（SK-1023 / SK-4419） | S1→S2 之间 |
| trends.csv | 行情趋势（SK-1023 +35%） | S1→S2 之间 |
| env_score.csv | 环境评分（家居家纺 -2 分） | S1→S2 之间 |
| promotion_calendar.csv | 大促日历（黑五等） | S0 seed 自动入 settings |
| purchase_orders_history.csv | 采购历史（在途/到货） | S5 验收 |

## 人工放入三条纪律（详见 03 方案第 6 节）

1. 严格按阶段时机放入，提前放会绕过对应阶段验收门（如 S2 前放 trends.csv，趋势修正器降级路径就测不到）。
2. 每次放入后必须手动触发重新测算（`POST /api/calc/run`）。
3. 降级测试（不传某文件）与正常测试成对做。
